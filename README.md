# Proposta mobile — Portfólio Israel Rhuston

Protótipo estático (HTML/CSS/JS, sem dependências). Abrir `index.html` num servidor local:
`npx serve .` → http://localhost:3000

- `index.html`: hero com showreel em vídeo, sobre, carrossel de projetos com scroll-snap, competências que se abrem ao toque, contacto com mailto/tel e menu em ecrã inteiro.
- `cartoonito.html`: página de caso cinematográfica, com vinhetas Vimeo que só carregam ao tocar.
- `robots.txt`, `sitemap.xml` e `.htaccess` (cabeçalhos de segurança e cache): sugestões, não aplicadas no site ao vivo.
- Os projetos sem página nova apontam para as páginas atuais do site ao vivo.
